Olist E-Commerce Analytics

An end-to-end e-commerce data analytics project focused on exploring sales performance, customer behavior, payment trends, and order delivery performance using Python and Power BI.

Project Overview

This project analyzes the Brazilian Olist e-commerce dataset to uncover meaningful business insights and understand key business performance indicators.

The workflow includes data cleaning, preprocessing, data analysis, data modeling, and interactive dashboard development.

Tools & Technologies

- Python – Data cleaning and preprocessing
- Pandas – Data manipulation and transformation
- Power BI – Interactive dashboards and data visualization
- DAX – Measures and calculated metrics

Dashboard Pages

The Power BI report contains four interactive pages:

1. Sales Overview – Sales performance and key business metrics.
2. Payment Analytics – Payment methods and payment value analysis.
3. Customer Analysis – Customer behavior and order patterns.
4. Order & Delivery Performance – Delivery trends, on-time performance, delays, and shipping costs.

Project Workflow

1. Explored the Olist e-commerce dataset.
2. Cleaned and preprocessed data using Python and Pandas.
3. Prepared data for analysis.
4. Built the data model and relationships in Power BI.
5. Created DAX measures for key performance indicators.
6. Designed interactive dashboards to communicate business insights.

Key Performance Areas

- Sales and revenue performance
- Payment value and payment methods
- Customer order behavior
- On-time delivery performance
- Late delivery analysis
- Average delivery time
- Shipping cost analysis

Project Status

Completed – Four interactive Power BI dashboard pages.
